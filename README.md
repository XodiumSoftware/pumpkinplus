## Overview

`pumpkinplus` is a [WASM](https://webassembly.org/) plugin for the [Pumpkin](https://github.com/Pumpkin-MC/Pumpkin) Minecraft server, written in Rust. It adds small quality-of-life enhancements to the base gameplay through a modular config-driven system.
